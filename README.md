# Smile Design Patients

Offline-first Android app for managing patient records with Excel (`.xlsx` / `.csv`) import and CSV backup export. No SMS, notification, or storage permissions required.

## Building the APK via GitHub Actions
1. Push all files (including `.github/workflows/build-apk.yml`) to the `main` branch.
2. Open the **Actions** tab and wait for **Build Patient Records APK** to finish.
3. Download **SmileDesign-Patients-APK** from Artifacts, unzip it, and install `app-debug.apk`.
